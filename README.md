# 📝 JavaScript Practice Set: Variables & Basics (Beginner Level)

---

## 🌸 Section 1: Pehchan Kaun? (Identification)

### ✨ 1. Keyword Hunt:

In mein se JavaScript ke "Keywords" kaunse hain aur normal "Words" kaunse?

```
let, myAge, const, var, userName, function, if, userCity.
```

---

### ✨ 2. Legal vs Illegal:

In mein se kaunse variable names JavaScript mein allowed hain?

```js
let 1stUser;

var user_name;

const @price;

let user123;
```

---

### ✨ 3. Difference:

var aur let mein koi ek barha farq batao jo tumne notes mein parha.

---

## 💻 Section 2: Karke Dekho (Practical Tasks)

### 🚀 4. The "Bio" Task:

Teen variables banao: myName (const), myAge (let), aur myHobby (let). Inhein console pe print karo.

---

### 🔄 5. Update Test:

Ek variable currentStatus = "Coding"; banao. Agli line mein uski value change karke "Sleeping" kar do. (Check karo let use karna hai ya const).

---

### ⚠️ 6. Const Error:

Ek variable const pi = 3.14; banao. Ab niche wali line mein pi = 3.15; likho. Console mein dekho kya error aata hai.

---

### 📦 7. Empty Variable:

Ek variable var test; declare karo lekin usko koi value mat do. Jab console pe test print karoge toh kya likha aayega?

---

### 🧠 8. Declaration vs Initialization:

Is code mein batao konsi line "Declaration" hai aur konsi "Initialization":

```js
var score;
score = 100;
```

---

## 🧩 Section 3: Dimagi Kasrat (Conceptual)

### 🪄 9. Hoisting Magic:

Agar tum console.log(a); pehle likho aur var a = 10; baad mein, toh error kyun nahi aata?

---

### ⚡ 10. The TDZ Trap:

let ke saath hoisting check karo. Kya let ko declare karne se pehle use kar sakte hain? Error ka naam kya hai?

---

### 📦 11. Inside the Box:

Ek { } (curly braces) ka block banao. Uske andar let x = "hidden"; rakho. Kya tum is x ko block ke bahar use kar sakte ho?

---

### 😏 12. The "Var" Problem:

Agar hum var x = 10; likhein aur phir dobara var x = 20; likh dein, toh kya JavaScript gussa karegi (error degi)?

---

### 🚫 13. Redeclaration Check:

let ke saath same naam ka variable dobara declare karke dekho. Kya result aata hai?

---

### 👨‍👧 14. The "Abba G" Rule (Const Logic):

Farz karo tum ek software bana rahe ho jisme user ka FatherName store karna hai. Kya tum iske liye const use karoge ya let? Wajah bhi batao ke agar koi ise let se banaye toh kya masla ho sakta hai?

---

### 🕵️‍♂️ 15. Window Object Ki Chori:

var aur let mein se kaunsa variable itna "badtameez" hai jo seedha ja kar browser ke window object mein ghuss jata hai aur wahan nazar aane lagta hai? Khud window.variableName likh kar check karo.
